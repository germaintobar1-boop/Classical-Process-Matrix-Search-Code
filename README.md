File checks the fixed point condition and outputs valid process matrices that satisfy the fixed point condition developed in Ämin Baumeler et al 2019 Class. Quantum Grav. 36 224002 and extended to multiple parties in Germain Tobar and Fabio Costa 2020 Class. Quantum Grav. 37 205011.

The file outputs a series of bits that correspond to co-efficients of multi-partite process matrices in the form of binary addition between sequential functions of the outputs of the individual parties of the process matrices.

This search program is what was used in Germain Tobar and Fabio Costa 2020 Class. Quantum Grav. 37 205011, and remains correct as it checks the fixed point condition, rather than the characterisation theorem which was later shown to have a counter example in Dourdent et. al. arXiv:2512.23599.
