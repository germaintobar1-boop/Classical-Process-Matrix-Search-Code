File checks the fixed point condition and outputs valid process matrices that satisfy the fixed point developed in Ämin Baumeler et al 2019 Class. Quantum Grav. 36 224002. 

The file outputs a series of bits that correspond to co-efficients of process matrices in the form of binary addition between sequential functions of the outputs of the process matrices that are added together through binary addition.

I.e.  a + b*x_1 + c*x_2 + d*x_3 + e *f_4 + g*x_1*x_2 + .... 

The addition used is binary addition.
